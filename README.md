## 🌟 Brand & Visual Identity

The brand identity is inspired directly by the Stack'd round logo:
- **Palette**: Royal Bubble Blue (`#2756E8`), Bubblegum Pink (`#FF2E7E`), Buttercup Sunshine Yellow (`#FFD12F`), Mint Pop (`#06D6A0`), and Cream Canvas (`#FFFDF9`).
- **Tactile 3D Buttons**: Pushable physical 3D pill buttons that bounce and click.
- **Typography**: Google Fonts **Fredoka** & **Plus Jakarta Sans**.
- **Mascots**:
  - **Blobby Blue**: The steady foundation with his signature orange swirl dollop hat giving a thumbs up!
  - **Pip Pink**: Chief Happiness Officer with sweet ear horns, rosy blush, and shopping tote!
  - **Sunny Cloud**: Chill winking yellow cloud buddy wearing headphones and sipping iced matcha!
  - **Minty Pop**: Mischievous turquoise berry friend popping out of gift boxes with confetti!

## 🛍️ Included Pages & Features

- **🏠 Home Page (`/`)**: Hero section featuring the 3D mascot stack tower, 4 value-prop cards, "Meet The Stack'd Crew", Top-rated drops, lifestyle tabletop room banner, custom bundle teaser, verified reviews, and Instagram community wall (`#KeepItStackd`).
- **📦 Shop All Goodies (`/shop`)**: Filterable catalog by category (Blind Boxes, Figures, Plushies, Drinkware, Desk Setup, Stationery), price range, in-stock only, search input, and sorting.
- **🔍 Product Detail Page (`/product/:id`)**: Multi-thumbnail gallery with zoom, variant selector, stock urgency alerts, mascot quote speech bubbles, tabbed technical specs & character lore, and verified customer reviews + review submission form.
- **🥞 Custom Stack & Save Builder (`/stack-builder`)**: Interactive custom bundle builder! Watch your stack grow visually into a vertical tower as you select items:
  - 3 Items = **10% OFF**
  - 5+ Items = **20% OFF + Free Worldwide Shipping**
- **🛒 Shopping Bag & Drawer (`/cart`)**: Slide-out cart drawer + dedicated Cart page with real-time Free Shipping progress meter ($50 threshold), coupon code engine (`STACK10`, `KEEPITSTACKED`, `FREESHIP`), and bundle savings calculator.
- **💳 Multi-Step Checkout (`/checkout`)**: Express checkout options, contact info, shipping address, delivery speed selection (Standard vs Express Air), simulated card/PayPal payment, order summary sidebar, and celebratory confetti upon completion.
- **🎉 Order Confirmation (`/order-success/:orderId`)**: Celebrating Mint mascot with confetti, unique order ID reference, live 4-step progress tracker (*Order Placed → Mascot Packing → In Transit → Delivered*), printable receipt, and courier tracking link.
- **📖 About Us (`/about`)**: The Stack'd story, brand philosophy, comprehensive character profiles, and sustainable toy crafting standards.
- **📬 Contact & FAQ (`/contact`)**: Customer care form, Blobby Blue support badge, business hours, direct Instagram DM links, and interactive FAQ accordion.
- **🚚 Live Order Tracker (`/track-order`)**: Real-time shipment tracking with order lookup and sample order preview.
- **💖 Wishlist (`/wishlist`)**: Saved favorites with 1-click Add to Stack buttons.
- **🤖 Interactive Mascot Buddy**: Floating bottom-right corner widget to chat with the mascots, get promo codes, and pop celebratory confetti!

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/fkazi72/stackd.git
   cd stackd
   ```

2. **Install dependencies**:
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser!

4. **Build for production**:
   ```bash
   npm run build
   ```
